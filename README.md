# GrokFilm 镜头导演

一个给 AI 视频创作者用的中文 Codex 技能。把一句剧情、一个画面想法或一段拍得不对劲的镜头交给它，它会帮你决定观众先看见什么、摄影机放在哪里、焦点何时移动，再写成可以直接使用的中文分镜或生成提示词。

比如，想拍「深夜回到办公室，发现搭档已经离职」，可以从一只手放下两杯咖啡开始。近处的第二杯先清晰，随后焦点移到对面的空工位，露出显示器底座在桌上留下的一圈浅色印子。观众看到第二杯是给谁买的，也明白这杯咖啡没人喝了。

适合做 AI 短剧、动态漫、广告和分镜预演。你可以让它设计一镜到底、写首帧或视频提示词，也可以拿已有素材来问「为什么我写了推轨，生成出来却像把画面放大了？」

## 安装与使用

1. [下载技能包 ZIP](https://raw.githubusercontent.com/boxsmall/grokfilm-director/main/grokfilm-director.zip) 并解压，得到 `grokfilm-director` 文件夹。
2. 把整个文件夹放入 Codex 的个人技能目录。macOS 和 Linux 可用 `~/.codex/skills/`，Windows 可用 `%USERPROFILE%\.codex\skills\`。安装后，文件夹内应能直接看到 `SKILL.md`。
3. 新开一个 Codex 聊天，复制下面这句话试试。

> 用 $grokfilm-director 把「深夜回办公室，发现搭档已经离职」拍成 8 秒竖屏一镜到底。没有对白，先让观众看见两杯咖啡，再发现空工位。给我一段可以直接复制的视频提示词，并告诉我看片时怎么判断移焦是否成功。
